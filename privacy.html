개인정보 처리방침

시행일: 2026년 11월 19일(의견 게시판 구글 로그인 반영) · 적용 대상: Mirago 웹(inhyeuk.github.io/mirago)과 Mirago PC·안드로이드 앱

1. 한눈에 보기

  • Mirago는 회원 가입이 없고(의견 게시판 글쓰기만 구글 계정 로그인), 영상 시청과 관련해 운영자 서버로 개인정보를 수집·저장하지 않습니다. 서버에 남는 것은 이용자가 직접 쓰는 의견 게시판 글(4장)과, 개인을 알 수 없는 날짜별 이용 합계(4-1장)뿐입니다.
  • 이어보기 위치·찜·설정 같은 이용 기록은 이용자 기기(브라우저 저장소)에만 저장됩니다.
  • Mirago는 YouTube API 서비스를 이용합니다. 영상은 YouTube 공식 플레이어로 재생되며, 재생 과정에서 YouTube(Google)가 정보를 처리할 수 있습니다. 이는 Google 개인정보처리방침을 따릅니다.

2. YouTube API 서비스 이용

Mirago는 YouTube API 서비스로 공개 영상의 제목·설명·재생 시간·조회수·채널 정보·썸네일 주소를 받아 작품별로 정리해 보여 줍니다. 이 정보는 공개된 영상 정보이며 이용자 개인정보가 아닙니다. 받은 정보는 30일 안에 다시 확인해 갱신하거나 삭제합니다.

Mirago를 이용하면 YouTube 서비스 약관에도 동의하게 됩니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

Mirago 운영자는 이 정보를 볼 수 없고 받지 않습니다. 쿠키를 직접 쓰지 않지만, 페이지에 넣은 YouTube 플레이어는 YouTube(Google)의 쿠키·유사 기술을 사용할 수 있습니다.

4. 의견 게시판

항목목적보관·삭제
구글 계정 로그인 정보(이메일 주소·이름·프로필 사진 주소, 계정별 게시판 ID)글쓰기·신고 자격 확인, 내 글 삭제, 운영자 확인Firebase 인증에 보관되며 게시판에 공개되지 않습니다. 로그인 상태는 이 기기의 브라우저 저장소에 남고 '로그아웃'으로 지웁니다. 계정 정보 삭제는 8장의 방법으로 요청할 수 있습니다.
닉네임, 분류, 글 내용, 작성 시각, 이용 환경(웹·PC 앱·안드로이드 앱 구분), 게시판 ID의견 게시·답변, 내 글 삭제, 도배 방지(1분 간격)글을 지울 때까지 보관(이용자가 직접 삭제 가능, 운영자는 규칙 위반 글 삭제).
신고 시: 신고 사유, 신고한 글, 신고자 게시판 ID, 시각문제 글 처리

글에는 닉네임만 공개되며, 구글 계정의 이메일·이름은 글에 넣지 않습니다. 글 읽기는 로그인 없이 됩니다. 글 내용에 개인정보를 적지 마세요 — 글은 누구나 볼 수 있습니다. 게시판 자료는 Google Firebase(Google LLC, 서울 리전 데이터베이스)에 저장됩니다.

4-1. 익명 이용 통계

서비스 개선을 위해 날짜별 합계 숫자만 Google Firebase에 기록합니다: 그날 접속한 기기 수, 처음 접속한 기기 수, 회차 재생 횟수(웹·PC 앱·안드로이드 앱 구분). 기기를 구분하는 ID·IP 주소·시청한 영상 목록은 Mirago에 저장하지 않으며, 합계 숫자로는 개인을 알아볼 수 없습니다. 같은 날 두 번 세지 않도록 '오늘 셌음' 표시만 이 기기의 브라우저 저장소에 남깁니다. 약관에 동의하기 전에는 기록하지 않습니다.

Mirago는 광고를 싣지 않고, 이용자 정보를 판매하거나 다른 곳에 제공하지 않습니다.

6. 아동

Mirago는 아동을 대상으로 하지 않으며, YouTube에서 '아동용'으로 지정된 영상은 목록에 넣지 않습니다.

7. 앱 권한

안드로이드 앱은 인터넷 접속 권한만 사용합니다. 위치·연락처·카메라·저장소 같은 권한은 요청하지 않습니다.

8. 이용자 권리와 문의

기기에 저장된 기록은 이용자가 직접 언제든 지울 수 있습니다. 게시판에 쓴 내 글은 같은 구글 계정으로 로그인해 직접 지울 수 있습니다. PC·안드로이드 앱에서 로그인하면 기본 브라우저에서 구글 로그인을 마친 뒤, 로그인 결과가 이 기기 안에서만 앱으로 넘어갑니다. 개인정보와 관련한 문의·요청은 의견 게시판이나 GitHub 문의 게시판에 남겨 주세요. 7일 안에 답하고, 요청한 정보가 Mirago 쪽에 있다면 7일 안에 삭제합니다.

9. 바뀌는 경우

이 방침을 바꾸면 이 페이지에 시행일과 함께 알립니다.
