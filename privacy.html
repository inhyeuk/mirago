개인정보 처리방침

시행일: 2026년 11월 16일(의견 게시판 추가 반영) · 적용 대상: Mirago 웹(inhyeuk.github.io/mirago)과 Mirago PC·안드로이드 앱

1. 한눈에 보기

  • Mirago는 회원 가입이 없고, 영상 시청과 관련해 운영자 서버로 개인정보를 수집·저장하지 않습니다. 예외는 이용자가 직접 글을 쓰는 의견 게시판뿐입니다(아래 4장).
  • 이어보기 위치·찜·설정 같은 이용 기록은 이용자 기기(브라우저 저장소)에만 저장됩니다.
  • Mirago는 YouTube API 서비스를 이용합니다. 영상은 YouTube 공식 플레이어로 재생되며, 재생 과정에서 YouTube(Google)가 정보를 처리할 수 있습니다. 이는 Google 개인정보처리방침을 따릅니다.

2. YouTube API 서비스 이용

Mirago는 YouTube API 서비스로 공개 영상의 제목·설명·재생 시간·조회수·채널 정보·썸네일 주소를 받아 작품별로 정리해 보여 줍니다. 이 정보는 공개된 영상 정보이며 이용자 개인정보가 아닙니다. 받은 정보는 30일 안에 다시 확인해 갱신하거나 삭제합니다.

Mirago를 이용하면 YouTube 서비스 약관에도 동의하게 됩니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

3. 이용자 기기에 저장하는 정보

항목목적보관·삭제
회차별 시청 위치·시청 시각이어보기, 다 본 회차 표시, 새 회차 알림이용자 기기에만 보관. '내 서재 › 시청 기록'의 '시청 기록 모두 지우기', 검색 화면의 '모두 지우기', 브라우저의 사이트 데이터 삭제, 앱 삭제(안드로이드) 또는 %LOCALAPPDATA%\Mirago 폴더 삭제(PC)로 언제든 지울 수 있습니다.
찜한 작품·숨긴 작품·최근 검색어내 서재, 숨기기, 검색 편의
설정(재생 속도, 자동 재생 여부, 정렬 등)·약관 동의 시각설정 유지

Mirago 운영자는 이 정보를 볼 수 없고 받지 않습니다. 쿠키를 직접 쓰지 않지만, 페이지에 넣은 YouTube 플레이어는 YouTube(Google)의 쿠키·유사 기술을 사용할 수 있습니다.

4. 의견 게시판

항목목적보관·삭제
닉네임, 분류, 글 내용, 작성 시각, 이용 환경(웹·PC 앱·안드로이드 앱 구분), 기기별 임의 게시판 ID(익명 로그인)의견 게시·답변, 내 글 삭제, 도배 방지(1분 간격)글을 지울 때까지 보관(이용자가 직접 삭제 가능, 운영자는 규칙 위반 글 삭제). 게시판 ID는 이 기기의 브라우저 저장소에도 저장되며 사이트 데이터를 지우면 새 ID가 만들어집니다.
신고 시: 신고 사유, 신고한 글, 신고자 게시판 ID, 시각문제 글 처리

게시판에는 이름·이메일·전화번호를 받지 않습니다. 글 내용에 개인정보를 적지 마세요 — 글은 누구나 볼 수 있습니다. 게시판 자료는 Google Firebase(Google LLC, 서울 리전 데이터베이스)에 저장됩니다.

제공 주체처리되는 정보관련 방침

Mirago는 광고를 싣지 않고, 이용자 정보를 판매하거나 다른 곳에 제공하지 않습니다.

6. 아동

Mirago는 아동을 대상으로 하지 않으며, YouTube에서 '아동용'으로 지정된 영상은 목록에 넣지 않습니다.

7. 앱 권한

안드로이드 앱은 인터넷 접속 권한만 사용합니다. 위치·연락처·카메라·저장소 같은 권한은 요청하지 않습니다.

8. 이용자 권리와 문의

기기에 저장된 기록은 이용자가 직접 언제든 지울 수 있습니다. 게시판에 쓴 내 글은 그 글을 쓴 기기에서 직접 지울 수 있습니다. 개인정보와 관련한 문의·요청은 의견 게시판이나 GitHub 문의 게시판에 남겨 주세요. 7일 안에 답하고, 요청한 정보가 Mirago 쪽에 있다면 7일 안에 삭제합니다.

9. 바뀌는 경우

이 방침을 바꾸면 이 페이지에 시행일과 함께 알립니다.
