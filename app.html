무료 · 최신 판

Windows PC

Windows 10·11 · 약 12MB · 관리자 권한 필요 없음

설치 파일 내려받기
설치 없이 쓰는 판(zip)
  1. MiragoSetup.exe를 실행하고 '확인'을 누르세요.
  2. 'Windows의 PC 보호' 창이 뜨면 추가 정보 → 실행을 누르세요.
  3. 바탕화면과 시작 메뉴에 Mirago가 생겨요.

F11로 전체 화면, F5로 새로고침. 지우려면 설정 › 앱 › 설치된 앱에서 Mirago를 제거하세요.

안드로이드

Android 7 이상 · 약 28MB · APK 직접 설치

APK 내려받기

PC에서 보고 계시면 휴대폰 카메라로 이 QR을 찍으세요. 바로 APK를 내려받아요.

  1. 내려받은 Mirago-android.apk를 누르세요.
  2. '출처를 알 수 없는 앱' 안내가 나오면 설정 → 이 출처 허용을 켜세요.
  3. '설치'를 누르면 끝. Play 프로텍트 안내가 뜨면 무시하고 설치를 고르세요.

자주 묻는 질문

웹과 앱은 무엇이 다른가요?

보는 작품과 기능은 같아요. 앱은 바탕화면·홈 화면에서 바로 열리고, 휴대폰 뒤로 버튼과 전체 화면 재생이 더 자연스러워요. 영상은 웹과 똑같이 YouTube 공식 플레이어로 재생되고, 앱을 내리거나 창을 최소화하면 재생이 멈춰요(YouTube 정책상 백그라운드 재생은 지원하지 않아요).

업데이트는 어떻게 하나요?

작품 목록과 화면은 매일 자동으로 새로워져요. 앱 자체가 바뀌는 새 판이 나오면 앱 안에 알림이 뜨고, 이 페이지에서 다시 받아 설치하면 돼요(이어보기·찜 기록은 그대로 남아요).

왜 '알 수 없는 앱'·'PC 보호' 안내가 뜨나요?

Mirago는 Play 스토어·Microsoft 스토어를 거치지 않고 개인이 직접 배포하는 무료 앱이라 이런 안내가 떠요. 이 페이지(inhyeuk.github.io/mirago)와 GitHub 릴리스에서 받은 파일만 설치하세요.

받은 파일이 진짜인지 확인하고 싶어요

릴리스마다 SHA256SUMS.txt가 함께 올라가요. 안드로이드 APK 서명 인증서 SHA-256: 0b1c1f3776631bf74d13338517d465762e261f2a0e6ad36c645fb107f476b795

WebView2가 필요하다고 나와요(PC)

Windows 10·11에는 보통 들어 있어요. 없다는 안내가 뜨면 Microsoft의 WebView2 런타임(무료)을 설치한 뒤 Mirago를 다시 여세요.
